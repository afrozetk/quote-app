# 📱 Quote Display Android App

An Android app that displays a motivational quote on launch.  
Built using Java and Android Studio as part of coursework for **IT 372 - Mobile App Development** at **DePaul University**.

---

## 📌 Features

- Simple, clean UI
- Displays an inspirational quote
- Uses ConstraintLayout for responsive design
- Built with Java and Android SDK

---

## 🛠 Tech Stack

- Java
- Android Studio
- XML Layout (ConstraintLayout)

---

## 💻 How to Run

1. Clone the repository or download the source code.
2. Open the project in **Android Studio**.
3. Connect an Android device or start an emulator.
4. Click **Run** to launch the app.
